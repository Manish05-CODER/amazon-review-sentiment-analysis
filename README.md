# amazon-review-sentiment-analysis
Multi-domain sentiment analysis of Amazon product reviews using machine learning

## Dataset Information

This project uses Amazon product review datasets from three domains:
- Groceries
- Clothing
- Appliances

The datasets are not included in this repository because of their large size. Please obtain the datasets from their original sources and place them inside the `data/` folder.

Update the dataset file paths in the notebooks according to your filenames before running them.
